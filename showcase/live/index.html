Quality gate

If tests fail, the merge request is blocked. The team looks at the failures, fixes the bugs and runs the pipeline again.

→ Merge & release

Release

Tests are green and reviewers approve: the code is merged into the main branch. The pipeline runs again and the new version goes to production.
